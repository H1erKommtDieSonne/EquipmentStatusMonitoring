Используется дерево хэшей по сетевому адресу устройства.
Ключ - 32-битный сетевой адрес устройства.  
Значение - список устройств с этим адресом.

Адрес разбивается на 4 байта. Каждый байт выбирает ветку дерева на своём уровне.
Например, адрес 3232235777 соответствует 192.168.1.1, поэтому путь в дереве будет:
корень - 192 - 168 - 1 - 1 - лист


Файлы
DeviceModel.hs - типы данных предметной области: устройство, адрес, приоритет, состояние
HashTree.hs - реализация дерева хэшей: добавление, поиск, удаление, построение из списка
HashTreeMonad.hs - монадная оболочка над деревом
DeviceParser.hs - чтение устройств из текстового файла
Tests.hs - тесты без внешних библиотек
Main.hs - демонстрационная программа
devices.txt - тестовые данные




Запуск в баше
cd haskell/practice8
ghci Main.hs
main




Что проверяю
добавление устройства в дерево
поиск устройства по сетевому адресу
поиск отсутствующего адреса
удаление устройства
построение дерева из списка
хранение нескольких устройств с одним адресом
последовательность операций через монаду
