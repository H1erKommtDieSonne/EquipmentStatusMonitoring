# Архитектура системы

Система состоит из двух уровней:

## C++ уровень

Реализует:

- бизнес-логику
- модели устройств
- систему ремонта
- работу с базой данных

Основные классы:

- Device
- HealthyDevice
- FaultyDeviceEx
- ReserveDevice
- Engine
