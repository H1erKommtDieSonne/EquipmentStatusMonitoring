# Equipment Status Monitoring

Система мониторинга оборудования и управления ремонтом.

## Возможности

- учёт устройств
- регистрация поломок
- управление ремонтными работами
- назначение работников
- приоритизация обслуживания

## Основные компоненты

- **Device** — базовый класс устройства
- **HealthyDevice** — исправное устройство
- **FaultyDeviceEx** — неисправное устройство
- **ReserveDevice** — резервное устройство
- **Engine** — центральный управляющий компонент
